# Project images

Create one folder per project. Use `cover.jpg` for the card image and additional screenshots for the detail carousel.

Recommended naming:

```text
images/projects/project-name/cover.jpg
images/projects/project-name/screen-1.jpg
images/projects/project-name/screen-2.jpg
images/projects/project-name/screen-3.jpg
```

Keep images optimized for the web. JPG, PNG, or WebP files work well.
